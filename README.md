# VideoStudio releases

Installers and update files for **VideoStudio**, the desktop video editor by
Ashok Siva Software Solutions.

- Download the latest installer from the [Releases](../../releases) page:
  `VideoStudio-Setup-<version>-x64.exe`.
- Installed copies of VideoStudio check this page for updates automatically.

This repository holds release files only. The source code is not published here.
